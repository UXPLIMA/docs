| Key | Default |
|---|---|
| `default-mode` | `anvil` (or `chat`, `sign`, `dialog`) |
| `cancel-keywords` | `cancel`, `iptal` |
| `modes."editor.value"` | `anvil`: the new value of one key |
| `modes."editor.message"` | `chat`: the new wording of one line |

A Bedrock player always gets a form.
