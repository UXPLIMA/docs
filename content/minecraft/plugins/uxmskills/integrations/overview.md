Nothing is required.

| Plugin | Gives |
|---|---|
| PlaceholderAPI | The [placeholders](../placeholders/reference.md), and other plugins' values in conditions |
| Vault, VaultUnlocked, Treasury, PlayerPoints, EcoBits | [Money backends](../config/economy-conf.md) |
| Nineteen claim plugins | [What land is worth](../features/experience.md#land) |
| Oraxen, Nexo, ItemsAdder, CraftEngine | Custom blocks and items in sources |
| MythicMobs, LevelledMobs, RoseStacker | Custom and stacked mobs in sources |
| CustomCrops, CustomFishing, PyroFishingPro, InfiniteFishing | Custom crops and catches in sources |
| mcMMO | Its values in conditions |
| AuraSkills | Its player files, read by `/uxmskills import` |
| Floodgate, Geyser | Forms for Bedrock players |

`/uxmskills doctor` says whether the currencies, claims and placeholders were found.
