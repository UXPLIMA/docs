| Plugin | What it is |
|---|---|
| [uxmClaims](uxmclaims/) | Land protection with GUI menus |
| [uxmHelperNPC](uxmhelpernpc/) | A personal NPC assistant with menus, actions, holograms and an AI assistant |
| [uxmSpawners](uxmspawners/) | Spawners that store what they produce, upgrade, stack boosts and sell from a menu |
| [uxmFarmer](uxmfarmer/) | A hired farmhand NPC that harvests, kills, collects XP and sells, with per-product levels |
| [uxmDiscordSync](uxmdiscordsync/) | Account linking, rank sync, chat bridge, Discord-side 2FA and level rewards |
| [uxmDragonEvent](uxmdragonevent/) | A scheduled Ender Dragon fight with rebirths, damage leaderboards and rewards |
| [uxmBlacksmith](uxmblacksmith/) | Time-gated crafting with burn risk, trade slots, boosts, levels, masteries and a perk tree |
| [uxmBuilders](uxmbuilders/) | Schematics a player buys and an NPC crew builds block by block, with a live preview |
| [uxmSupplyRush](uxmsupplyrush/) | Timed item tournaments: players deposit items for points and the top contributors win rewards |
| [uxmEssentials](uxmessentials/) | The essentials suite: 35 modules, from homes, warps and economy to moderation, NPCs, holograms and menus |
| [uxmChat](uxmchat/) | Chat for one server or a network: channels, formats, private messages, friends, tags and colours |
| [uxmAuth](uxmauth/) | Login and registration for offline-mode servers and networks, on Paper, Folia and Velocity |
| [uxmPlots](uxmplots/) | Plot worlds for creative and building servers, with a gallery, contests, renting and protection |
| [uxmSimpleClaims](uxmsimpleclaims/) | Chunk claims with roles, flags, sub areas with rent, a market, warps, taxes and time limits |
| [uxmJobs](uxmjobs/) | Jobs that pay players for breaking, placing, killing, fishing, smelting and more |
| [uxmSkills](uxmskills/) | Skills that level as players mine, fight, farm, fish and more |
| [uxmCrates](uxmcrates/) | Crates whose odds a player can read, with reveal animations, keys, milestones and envoys |
| [uxmAuction](uxmauction/) | An auction house with fixed prices, bids, buy orders and a mailbox for what players are owed |
| [uxmShop](uxmshop/) | A server shop from a catalogue and player shops, in one plugin |
| [uxmQuests](uxmquests/) | Quests in any number of languages, dealt per player or shared, with a battle pass |
| [uxmMinions](uxmminions/) | Small workers that mine, chop, farm, fish, fight, collect and sell on their own |
| [uxmCosmetics](uxmcosmetics/) | A wardrobe of cosmetics in twelve categories, from trails and pets to emotes and gadgets |
| [uxmEnchants](uxmenchants/) | Custom enchantments, one file each, in the enchanting table, trades, loot, the anvil and books |
| [uxmLevels](uxmlevels/) | Experience and levels on as many tracks as a server wants |
| [uxmBackup](uxmbackup/) | Backups taken from inside the server: worlds, files and databases into checked zip archives |
| [uxmParkour](uxmparkour/) | Endless parkour generated in front of the player, with themes, difficulties and leaderboards |
| [uxmKotl](uxmkotl/) | King of the Ladder: climb to the plate, hold it, knock the others off |
| [uxmEasterEggs](uxmeastereggs/) | Eggs hidden around the map for players to hunt, with rewards and leaderboards |
| [uxmDailyRewards](uxmdailyrewards/) | One reward a day from a calendar, with streaks |
| [uxmHubPvP](uxmhubpvp/) | Sword fights in the lobby for the players who choose them |
| [uxmLang](uxmlang/) | One language per player across the server, or across a network that shares a database |
| [uxmMultiLobby](uxmmultilobby/) | A menu of your lobbies with live player counts that moves a player to the one they click |
| [uxmMOTD](uxmmotd/) | The server list entry: description lines, the hover list and the icon, per player language |
| [uxmJoinItems](uxmjoinitems/) | The hotbar items a lobby hands out on join, first join, respawn or world change |
| [uxmGlow](uxmglow/) | A glowing outline a player picks for themselves, in one of the 16 team colours or several in turn |
| [uxmPlayerHider](uxmplayerhider/) | A hotbar item and a command to show everybody, only the important players, or nobody |
| [uxmTeleportBow](uxmteleportbow/) | A bow whose arrow carries the player to where it lands |
| [uxmJumpPads](uxmjumppads/) | Jump pads that throw a player where they point |
| [uxmHeads](uxmheads/) | A player's face drawn in chat from their skin |
