| Plugin | Adds | Without it |
|---|---|---|
| Vault, VaultUnlocked, PlayerPoints, EcoBits, Treasury | Prices in that economy | Prices in experience or levels |
| PlaceholderAPI | The placeholders | `/uxmcosmetics doctor` warns; the rest works |
| A permission plugin | Granting pieces and boxes by node | Operators only |
| Geyser, Floodgate | Windows as Bedrock forms | Bedrock players get chest windows |
| uxmLang | One language choice for every UXM plugin | The choice is kept in `languages.conf` |

Related: [Economies](economies.md), [PlaceholderAPI](placeholderapi.md)
