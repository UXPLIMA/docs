uxmCrates is a crate plugin that tells the truth. Every reward a crate can give is in its preview, next to the
chance that player really has of winning it, and that chance comes from the same arithmetic the draw rolls
against. The reward is decided and written down before the first frame of the reveal, so a skipped animation, a
closed window, a full inventory, a logout or a restart never loses what a player won.

## What it does

| Part | What it gives you |
|---|---|
| Crates | Any number, one file each: a block in the world, or a window opened by command |
| Rewards | Items, console commands and money, in weighted groups, with limits, guarantees and linked rewards |
| Keys | A virtual balance, a physical item, or either; tradeable or not; craftable at a bench |
| Reveals | Fourteen shipped animations: windows, reels, and display entities drawn per viewer with packets |
| Previews | Every reward with its weight and the reader's own chance, one page per group |
| Bulk opening | Every key at once, up to a cap, with one summary window |
| Pick crates | The player chooses rewards instead of rolling |
| Rerolls | Roll again, from a rank ladder, a grant or a price |
| Milestones | Rewards for opening a number of one crate, or of any crate |
| Envoys | Crates that fall across an area on a schedule and vanish again |
| The log | Every win with the chance it had at that moment, by player, crate or reward |
| The editor | Crates, keys and rewards built in windows, written to the same files |
| Boards | All time, monthly, weekly and daily boards of crates opened |
| Migration | Reads ExcellentCrates, CrazyCrates and SpecializedCrates |

## Who it is for

A server that sells or hands out keys and wants players to trust the table. It runs on a single Paper server or a
network sharing one database, where key balances, limits and boards follow a player everywhere.
