| Plugin | Adds | Without it |
|---|---|---|
| PlaceholderAPI | The [placeholders](../placeholders/reference.md) | The doctor warns; the rest works |
| A permission plugin | Colours per rank | Operators hold every colour |
| uxmChat or any UXM plugin that writes a nametag | A tag and a glow on one name, through uxmLib's shared nametag | Nothing to share |
| Geyser or Floodgate | The picker as a Bedrock form | Bedrock players get the chest window |
| uxmLang | One language choice for every UXM plugin | The choice is kept in `languages.conf` |

uxmGlow needs nothing else installed: no economy, no PlaceholderAPI, no permissions plugin beyond the one your server
already runs.

Related: [Nametags](../features/nametags.md)
