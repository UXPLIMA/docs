| Plugin | Adds |
|---|---|
| Every UXM plugin | Reads the choice through uxmLib's language service; see [Other plugins](../features/other-plugins.md) |
| Floodgate, Geyser | The window as a Bedrock form |
| PlaceholderAPI | Placeholders in effect lines |
| Vault | `[give-money]` and `[take-money]` in effect lines; a server with no economy refuses those two lines |
| mcMMO | `%mcmmo_level_<skill>%` in effect lines, read without PlaceholderAPI |
| Redis | Instant changes across a network; see [A network](../features/network.md) |

Every one of these is reached only when it is installed.

Related: [Installation](../getting-started/installation.md)
