| Plugin | Adds |
|---|---|
| WorldGuard | `regions` on an item |
| PlaceholderAPI | `skip-when` guards, placeholders in action lines |
| Vault | `[give-money]` and `[take-money]` |
| mcMMO | `%mcmmo_level_<skill>%` in action lines |
| A proxy | `[server]` moves a player through BungeeCord, Waterfall or Velocity |
| uxmCosmetics | The shipped `cosmetics` item runs `/cosmetics` |
| uxmMultiLobby | The shipped `lobby` item runs `/lobby`; turn off uxmMultiLobby's own hotbar tool so the two do not both hand one out |
| uxmKotl, uxmParkour | Their `arena` placeholders make good `skip-when` guards |
| uxmLang | One language choice for every UXM plugin |

Every one of these is reached only when it is installed.
