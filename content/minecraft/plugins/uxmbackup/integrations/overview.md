| Plugin or service | Adds |
|---|---|
| SFTP, S3 (AWS, MinIO, Backblaze B2, Wasabi, Hetzner), WebDAV (Nextcloud and others), FTPS | Remote [storages](../features/storages.md) |
| SQLite, MySQL, MariaDB, PostgreSQL | [Database dumps](../features/databases.md) without external tools |
| Every UXM plugin | Writes its state to disk before a set is read, through uxmLib |
| Discord | A webhook message when a run ends |
| PlaceholderAPI | The [placeholders](../placeholders/reference.md) |
| uxmLang | One language choice for every UXM plugin |

Related: [A run](../features/a-run.md)
