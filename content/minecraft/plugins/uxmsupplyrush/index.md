uxmSupplyRush runs item collection tournaments. You choose which items count and how many points
each one is worth, start the event, and players hand in those items from a menu while the clock
runs. When time is up, the leaderboard is final and the top players are paid automatically, even
if they are offline at that moment.

Everything is set up in game: creating an event, picking its items, setting its length and
starting it. Rewards and announcements live in one file per event, and a weekly schedule can start
events on its own. On a network, one tournament can run across every server at once.
