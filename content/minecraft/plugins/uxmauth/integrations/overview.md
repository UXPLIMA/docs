| With | Adds |
|---|---|
| Velocity | The network: signed claims, routing, the proxy's handshake |
| LimboAPI 1.1 or 2 | The proxy's own waiting world |
| Floodgate, Geyser | Bedrock players and native forms |
| PlaceholderAPI | The placeholders, and placeholders in effects |
| ViaVersion | Older clients; one older than 1.21.6 waits frozen instead of at the dialog |
| Vault | Money in effect lines |
| Redis | Instant news across a network |
| MaxMind GeoLite2 | Country rules |
| Mojang, PlayerDB, Minetools, Ashcon | Premium name checks |
| Have I Been Pwned | The optional breach check |
| An SMTP server | Mail |
| Discord | The staff webhook |
| A website panel such as LeaderOS or Minexon | The website table |
| Eleven login plugins | A one-time import |

Every one of these is reached only when it is set up.
