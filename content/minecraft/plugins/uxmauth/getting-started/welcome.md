An offline-mode server lets anybody join under any name. uxmAuth puts a door in front of it: a player registers a
password the first time and logs in with it after, a player who owns the name at Mojang proves it and walks in, and a
Bedrock player Floodgate vouched for walks in too. Behind the door sit sessions, address bans, a captcha, a second
factor, mail recovery, and the staff tools to run it.

## What it does

| Part | What it gives you |
|---|---|
| [The waiting room](../features/waiting-room.md) | A dialog before the world, a frozen player, or an empty login world |
| [Passwords](../features/passwords.md) | Rules, a common-password list, a breach check, Argon2id and three more algorithms |
| [Sessions](../features/sessions.md) | A player back from the same address skips the password |
| [Premium names](../features/premium.md) | Four ownership rules, four UUID schemes, four ways to settle a name two players want |
| [Bedrock](../features/bedrock.md) | Floodgate players in without a password, or with a native form |
| [Protection](../features/protection.md) | Address bans, connection and account limits, filters, countries |
| [Captcha](../features/captcha.md) | A code as text or drawn on a map |
| [Second factor](../features/second-factor.md) | An authenticator app or a code by mail, backup codes, required for staff |
| [Mail and recovery](../features/mail.md) | A linked address, a forgotten password, the login code by mail |
| [Effects](../features/effects.md) | Titles, bars and sounds for every moment of the door |
| [Staff tools](../features/staff.md) | Info, history, alerts, Discord, console-only commands, purge |
| [Website table](../features/website-table.md) | A website's login table kept beside the plugin's own |
| [A network](../features/network.md) | Velocity and every server behind it as one door, with signed claims |

Every screen, command and line a player reads can be changed, in seven languages.
