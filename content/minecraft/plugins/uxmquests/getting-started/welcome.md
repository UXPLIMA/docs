uxmQuests gives a server quests that read in every language it has: daily boards that reset on a schedule, catalogues a
player picks quests from, boards the whole server works on together, milestones over a player's record, and battle
passes with a free and a premium track. Quests, passes, windows, messages and commands are files you edit.

## What it does

| Part | What it gives you |
|---|---|
| [Groups and boards](../features/groups-and-boards.md) | A file per group; a board of quests drawn per player, by rarity, with rerolls |
| [Resets](../features/resets.md) | Wall clock, rolling, cron or never, always in a timezone the file names |
| [Catalogues](../features/catalogues.md) | Every quest on offer, with categories, prerequisites and cooldowns |
| [Quests and tasks](../features/quests-and-tasks.md) | Tasks, amounts drawn from a span, filters and draws, rules for how many and in what order |
| [Task types](../features/task-types.md) | Fifty four things a task can count, from blocks and mobs to placeholders and triggers |
| [Anti-glitch](../features/anti-glitch.md) | Three levels that stop placing and breaking the same block |
| [Rewards and milestones](../features/rewards.md) | Action lines, set rewards, milestones per group and over a whole record |
| [Shared boards](../features/shared-boards.md) | One board the server works on, each player paid for their own work |
| [Feedback](../features/feedback.md) | What a player sees when a quest starts, moves, finishes and pays |
| [Ranks](../features/ranks.md) | Bigger boards and more rerolls by permission |
| [Battle pass](../features/battle-pass.md) | Ladders of tiers over two tracks, seasons, unclaimed rewards |
| [Pass experience and boosters](../features/pass-experience.md) | Experience from quests and raw play, boosters, the top and a board in the world |
| [Languages](../features/languages.md) | Every quest, group and pass in each reader's language |
