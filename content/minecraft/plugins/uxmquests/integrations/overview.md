Nothing is required; each is reached only when present.

| Plugin | Gives |
|---|---|
| PlaceholderAPI | `%placeholders%` in reward lines and `placeholder` tasks |
| Vault | `[give-money]` and `[take-money]` through the server's economy |
| CoreProtect | The third [anti-glitch](../features/anti-glitch.md) level, when `anti-glitch.coreprotect = true` |
| mcMMO | Skill levels in a line's condition |
| uxmShop | The `shop-buy` and `shop-sell` task types |
| Floodgate, Geyser | Bedrock players get forms where a window would be a chest |
| uxmLang | One language choice for every UXM plugin |

CoreProtect turned on and missing is said once in the console; the other levels keep working.
