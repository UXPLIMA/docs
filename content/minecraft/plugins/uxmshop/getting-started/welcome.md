uxmShop is two shops in one plugin. The catalogue is the half where the server is the counterparty: sections you write
as files, bought from with `/shop`, sold to with `/sell`. Player shops are the half where another player is: a container
in the world with stock kept in the database. Both share the currencies, the trade log, the storage and the windows.

## What it does

| Part | What it gives you |
|---|---|
| [Sections and lines](../features/sections-and-lines.md) | One file per section; item, command, shortcut, decoration and blank lines; rotation |
| [Item matching](../features/item-matching.md) | How strictly a sold item must match, chosen per line |
| [Prices](../features/prices.md) | Dynamic bands, ranks, modifiers, rounding and tax, in a fixed order |
| [Stock and quotas](../features/stock-and-quotas.md) | Server stock that refills, and per player allowances |
| [Selling](../features/selling.md) | `/sell hand`, `all`, `window`, and `/value` |
| [Trade effects and the log](../features/trade-effects.md) | What every trade says and plays, the blacklist, and the audit trail |
| [Player shops](../features/player-shops.md) | Shops behind containers, stock in the database, staff, limits, server shops |
| [The shop hologram](../features/hologram.md) | Text over a shop sent as packets, never an entity |
| [Currencies](../features/currencies.md) | Nine currency types, from Vault to a bridge you describe by hand |
| [The editor](../features/editor.md) | `/shopedit` changes sections and window tiles in game |
