| Plugin | Adds |
|---|---|
| LuckPerms | Prefixes, suffixes, meta and groups for formats; group formats, group tags, group colour defaults |
| PlaceholderAPI | Placeholders in formats, announcements, events and conditions; uxmChat's own [placeholders](../placeholders/reference.md) |
| Vault | Money for `[money]`, the `coins` currency, `[give-money]` rewards |
| PlayerPoints | Points as a tag currency |
| Treasury | Treasury currencies for tag purchases |
| Floodgate, Geyser | Bedrock players recognised: forms for windows and snapshots, the Bedrock drawing of a line |
| AuthMe, nLogin, LibreLogin | Chat stays closed until a player logs in |
| uxmEssentials | Its moderation's mutes; it steps back from the chat modules uxmChat runs. See [uxmEssentials](uxmessentials.md) |
| LiteBans, LibertyBans, AdvancedBan, Essentials | Their mutes. See [Punishment plugins](punishment-plugins.md) |
| uxmLang | One language choice for every UXM plugin |
| uxmTags, uxmChatColor | Read once and imported. See [Migration](migration.md) |
| Velocity | One chat across a network, with `uxmChat-Velocity`. See [A network](../features/network.md) |
| Discord | Bridges, events and `/online`, with `uxmChat-Discord`. See [Discord](../features/discord.md) |

Every one of these is reached only when it is installed; the plugin runs fully without any of them.
