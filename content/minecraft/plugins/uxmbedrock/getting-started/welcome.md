Geyser lets Bedrock Edition players join a Java server, and draws the server the way Bedrock can draw it: sixteen
colours, Bedrock's own font, chests for every menu, vanilla textures for custom items. uxmBedrock closes that gap. Java
players are never touched: every change is made only on the connections of Bedrock players.

| Part | What a Bedrock player gets |
|---|---|
| Text | Hex colours and gradients drawn exactly, Java's font, `<head:Name>` faces, the pictures of other plugins' fonts |
| Screens | The player list, scoreboard, titles, boss bars, name tags and holograms with that text; score numbers Java does not show hidden; chat laid out as on Java |
| Menus | Chest menus of other plugins as native forms, sign editors and anvils as forms, custom menu backgrounds drawn over the Bedrock screen |
| Pack | The server's resource packs (Nexo, ItemsAdder, Oraxen, CraftEngine, HUD plugins, your own) converted into a Bedrock pack: items, 3D models, armour, blocks, sounds, fonts |
| HUD | The HUD of HUD plugins drawn instead of their boss bars |
| World | Furniture and decorations of item plugins, custom heads with their skins |
| Choices | `/bedrock`: each player switches off what their device does not need, and chooses how much animation to download |

It runs on Paper and Folia 26.2 to 26.4 with Floodgate, beside Geyser on the same server or on a Velocity proxy.
